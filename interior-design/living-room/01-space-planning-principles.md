# 客廳空間規劃：大師手法整理（柱子多的客廳）

- 整理日期：2026-11-04
- 目的：拿到平面圖之前，先整理適合「柱子多的客廳」的規劃手法。拿到平面圖後，直接套用到實際配置。

---

## 一、可以借用的大師觀念

| 大師／來源 | 核心觀念 | 用在柱子多的客廳 |
|-----------|---------|------------------|
| **密斯・凡德羅**（Mies van der Rohe，巴塞隆納館） | 自由平面：柱子負責承重，牆和隔間另外安排，兩者分開 | 柱子不一定要包進牆裡。離牆有距離的獨立柱可以保持細、乾淨，讓它單獨立著，當作空間裡的「記號」 |
| **柯比意**（Le Corbusier） | 自由平面＋人體尺度（Modulor） | 先用人的尺寸決定走道和家具距離，再回頭處理柱子 |
| **亞歷山大**（Christopher Alexander，《建築模式語言》） | 座位圈、親密度漸層、凹室、窗邊座、柱旁的停留點 | 見下方說明 |
| **安藤忠雄、John Pawson（極簡）／日本的「間」** | 留白、材質種類少、光線是主角 | 柱子多的空間更要減少材質和顏色，不然會顯得很亂 |
| **台灣常見實務做法** | 以櫃藏柱、電視牆拉平包柱、假柱對稱、樑下做櫃或間接照明 | 台灣房子柱子多，這些是最常見也最省空間的處理方式 |

### 《建築模式語言》裡跟客廳最相關的幾個概念

- **座位圈（Sitting Circle）**：座位要圍成可以面對面聊天的形狀。主要動線不能從座位圈中間穿過，只能從旁邊經過。
- **親密度漸層（Intimacy Gradient）**：從入口開始，依序是公共區、半公共區、私密區。玄關看出去不要直接看穿整個家。
- **凹室（Alcoves）**：大空間旁邊的小角落讓人想停下來。**兩根柱子之間，或柱子和牆之間凹進去的地方，正適合做成凹室**，例如臥榻、閱讀角或書桌。
- **窗邊座（Window Place）**：窗邊要有一個可以坐下來的地方。
- **柱旁的停留點（Column Place）**：柱子旁邊是天然的停留點，可以在柱邊放單椅、邊几、落地燈或植栽，不要只想著把柱子藏起來。

## 二、依柱子位置選處理方式

| 柱子位置 | 建議做法 | 注意 |
|---------|---------|------|
| **貼牆、凸出牆面**（壁柱、角柱） | **以櫃藏柱**：在柱子旁邊做櫃子，櫃深跟柱面拉齊，整面牆看起來是平的。凸出 30–60 cm 剛好做書櫃（深 30–35 cm）或收納櫃 | 拉齊之後客廳會變窄，先確認走道寬度還夠 |
| **在電視牆上** | 整面電視牆拉平，把柱子吃進牆裡；只有一側有柱子時，另一側做**假柱**讓兩邊對稱 | 電視要放在拉平後那面牆的中心，不是原本牆的中心 |
| **在沙發背牆上** | 沙發背牆做淺櫃或層板拉平；或把沙發放在兩柱之間，柱子當沙發兩側的「框」 | 沙發不要卡進太窄的凹處，兩側至少各留約 10 cm |
| **獨立柱在空間中間** | 當作**分區界線**（客廳／餐廳／玄關的分界）；或做成展示柱、繞柱放邊几或座位 | 淺色或跟牆同色會比較不顯眼。鏡面包柱看起來比較輕，但會反射電視和燈光，要小心 |
| **剛好在動線上** | 調整家具，讓柱子落在「區與區之間」，不要落在走道正中間 | 柱子到家具之間的淨寬至少 75 cm，主要走道 90 cm 以上 |
| **兩柱之間有凹處** | 做成凹室：臥榻、書桌、展示櫃、鋼琴、收納 | 凹室深度 60 cm 以上才坐得舒服 |
| **在窗邊** | 窗邊座、植栽角、閱讀椅 | 不要擋住開窗和冷氣出風 |

**樑**：柱子兩兩相連的位置通常有大樑。沙發或座位最好不要直接坐在樑下。樑下可以順著做櫃子，或在天花板做間接照明來修飾。

## 三、常用尺寸（台灣常見）

| 項目 | 尺寸 |
|------|------|
| 主要走道淨寬 | ≥ 90 cm |
| 次要走道淨寬 | 60–75 cm |
| 沙發到茶几 | 35–45 cm |
| 茶几到電視櫃 | ≥ 75 cm（要能走過去） |
| 沙發座深 | 85–100 cm |
| 三人沙發寬 | 200–240 cm |
| 茶几長度 | 約沙發長度的 2/3 |
| 電視觀看距離（4K） | 約 吋數 × 2.54 × 1.2–1.5 cm（65 吋 → 約 2.0–2.5 m） |
| 電視中心高度 | 約 100–110 cm（坐著的視線高度） |
| 電視櫃深 | 40–45 cm |
| 書櫃深 | 30–35 cm |
| 座位圈（好聊天的距離） | 座位之間不超過約 2.4–3 m |
| 地毯 | 至少讓沙發前腳壓在地毯上 |

## 四、規劃步驟

1. **讀圖**：在平面圖上標出柱子、樑、窗、門、陽台，以及冷氣、插座、網路／第四台出口。
2. **先畫動線**：從入口到客廳、餐廳、走廊、陽台，先把走道畫出來（主要走道 ≥ 90 cm）。
3. **用柱子分區**：看哪些柱子剛好可以當玄關、客廳、餐廳的分界。
4. **選主牆**：決定電視牆和沙發背牆。優先選「有柱子可以拉平」的牆。
5. **擺家具**：先放沙發和座位圈，再用上面的尺寸表檢查。
6. **處理剩下的柱子**：凹室、收納、展示、柱邊的停留點。
7. **最後檢查**：採光、從玄關看進來的視線、插座位置、冷氣出風會不會直吹沙發。

## 五、要請你提供的資料

拿到下面這些資料，就可以畫平面配置圖：

1. **平面圖**：照片或檔案都可以，有尺寸最好。
2. **每根柱子**的尺寸（寬 × 深）和位置；樑的位置，以及樑下高度（如果知道）。
3. **天花板高度**。
4. **窗、門、陽台**的位置和寬度。
5. **冷氣、插座、網路／第四台出口**的位置（如果知道）。
6. **生活需求**：
   - 幾個人住？有沒有小孩或寵物？
   - 要不要電視？幾吋？還是用投影？
   - 想要哪種沙發（一字型、L 型）？已經有的家具要不要保留？
   - 收納需求（書、玩具、雜物）
   - 喜歡的風格
7. **客廳跟哪些空間相連**：餐廳、玄關、書房，或是開放式廚房？
